## 一、BitTorrent 概述

### 1.1 什么是 BitTorrent

BitTorrent 是 Bram Cohen 于 2001 年设计的 P2P 文件分发协议，通过用户之间互相分享文件片段，实现高效的大文件分发。

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  BitTorrent 核心特点：                                     │
│                                                             │
│  1. 去中心化：文件分散存储在所有用户节点                   │
│  2. 高效分发：用户越多，速度越快                          │
│  3. 断点续传：支持分片下载，可随时暂停恢复                │
│  4. 激励分享：上传越多，可下载越快                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
